# Demo Video Script (3–5 minutes)

1. **Introduction (20 sec):** State the problem: one assistant for career, learning, coding and document research.
2. **Application overview (30 sec):** Show the Streamlit interface and explain the LLM integration.
3. **RAG demonstration (60 sec):** Upload a sample PDF or DOCX, index it, ask a question answered by the document, and point out the source filename.
4. **Agent/tool demonstration (40 sec):** Ask a calculation question such as `What is (125 * 8) / 5?` and explain the calculator tool call.
5. **Prompt engineering (30 sec):** Explain grounding, uncertainty handling and source attribution in the system prompt.
6. **Engineering (40 sec):** Show the repository structure, tests and GitHub Actions workflow.
7. **Deployment (30 sec):** Open the deployed Streamlit URL and run a simple query.
8. **Conclusion (20 sec):** Summarize the stack and future improvements.

Use a non-confidential sample document and never show API keys in the recording.
