I’m excited to share a hands-on project: **AI Agents, Tools & Automation**.

In this project, I built a tool-using AI agent that follows a practical workflow:

**Understand Task → Decide Action → Use Tool → Process Result → Respond**

Key features:
- LLM-powered tool selection using function calling
- Calculator tool for arithmetic tasks
- Task management tools to add, list, and complete tasks
- SQLite database for persistent task storage and conversation history
- Bounded tool execution and basic input validation

This project helped me understand the difference between a traditional chatbot and an AI agent that can take actions through explicitly registered tools.

**Tech stack:** Python, OpenAI API, Function Calling, SQLite, python-dotenv.
